# Beacon PHP 1.0.0

Beacon PHP 1.0.0 is the first stable GitHub release of the Beacon Composer base package. It provides the Beacon version identity, diagnostics, and pinned compatibility ranges for the OpenTelemetry API, SDK, OTLP exporter, and the separately maintained Beacon PHP instrumentation extension.

## Supported scope

- PHP 8.2 and PHP 8.4 on Ubuntu 24.04 are validated from clean environments.
- `beacon-php doctor` validates the runtime, Beacon extension identity, and required OpenTelemetry packages.
- OTLP/HTTP protobuf trace export is validated against OpenTelemetry Collector Contrib 0.161.0.
- Framework instrumentation remains opt-in. Applications install the required `open-telemetry/opentelemetry-auto-*` packages separately.

## Installation

Download `beacon-php-1.0.0.zip`, `LICENSE`, and `SHA256SUMS` from this release, verify the checksum, and expose the directory containing the ZIP as a Composer artifact repository:

```bash
sha256sum --check SHA256SUMS
composer config repositories.beacon artifact /path/to/downloaded/artifacts
composer require beacon-observability/beacon-php:1.0.0
vendor/bin/beacon-php doctor
```

The Beacon PHP instrumentation extension is distributed separately. Install its `v0.1.0` build for the matching PHP runtime before running the diagnostic command.

## Known limitations

- The Composer base package is distributed as a GitHub release artifact. It is not yet available through public Packagist because its source lives in the `beacon-package/` monorepo subtree.
- Prebuilt extension archives cover the runtime and platform combinations published by `beacon-php-instrumentation` v0.1.0. Other environments require a source build and are not part of this release acceptance matrix.
- This release validates the base package and OTLP export path. It does not declare every Contrib framework integration supported as a Beacon component.

## Upgrade and rollback

This is the first stable release, so there is no earlier stable Beacon PHP package to upgrade from. Commit `composer.json` and `composer.lock` before installation. To roll back, restore both files, run `composer install`, and restore the previously installed instrumentation extension and PHP configuration.
