# Beacon PHP 1.2.1

Beacon PHP 1.2.1 fixes release installation guidance. Beacon PHP is currently distributed as
immutable GitHub Release ZIP assets, not through Packagist. A plain `composer require` in an
unconfigured project cannot resolve the Agent package.

Download this release's ZIP, LICENSE and SHA256SUMS, verify the checksums, and configure Composer
with an artifact repository pointing at that release directory before requiring version `1.2.1`.
PHP's `zip` extension is required by Composer's artifact repository. Follow the complete
[release-archive installation instructions](https://github.com/beacon-observability/beacon-php/blob/v1.2.1/README.md#installation).

The release workflow explicitly enables ZIP tooling and validates checksums, installed Security
hooks and real HTTP request isolation using the generated release artifact. Post-publication
acceptance repeats the documented installation command against the downloaded formal assets.

The opt-in Security capability introduced in 1.2.0 is unchanged: conservative findings, runtime
SBOM and OTLP Logs remain experimental and disabled by default. Native instrumentation stays
pinned to Beacon PHP Instrumentation 1.0.1 / upstream engine 1.4.2.
