This patch improves installation and upgrade guidance for Beacon PHP.

- Added complete installation instructions for GitHub Release ZIP assets, including Composer artifact-repository configuration, SHA-256 verification, and the required PHP `zip` extension.
- The experimental Security capability introduced in 1.2.0 is unchanged: runtime findings and SBOM over OTLP Logs, disabled by default.

See the [installation guide](https://github.com/beacon-observability/beacon-php/blob/v1.2.1/README.md#installation) and [Security configuration](https://github.com/beacon-observability/beacon-php/blob/v1.2.1/docs/security.md).
