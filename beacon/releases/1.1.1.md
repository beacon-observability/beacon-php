# Beacon PHP 1.1.1

Beacon PHP 1.1.1 is the production replacement for 1.1.0.

It contains the same two-repository Agent architecture, official OpenTelemetry component registry, installer, diagnostics, and PDO-to-OTLP validation introduced in 1.1.0. This patch release fixes release packaging so CI-only extension sources, Collector binaries, and temporary validation files cannot enter the Composer artifact.

The release workflow now rejects development paths and any unexpectedly large package before publication.

## Upgrade

```bash
composer require beacon-observability/beacon-php:1.1.1
vendor/bin/beacon-php doctor
```

Do not deploy the oversized `1.1.0` GitHub artifact. Its source tag remains immutable for auditability, but 1.1.1 is the supported release.
