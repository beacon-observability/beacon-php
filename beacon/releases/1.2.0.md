# Beacon PHP 1.2.0

Beacon PHP 1.2.0 adds experimental, opt-in Beacon Security runtime observations and runtime SBOM,
using the application's existing OpenTelemetry Logs provider and OTLP configuration.

## Security

- Conservative SQL template, command execution, filesystem path, and HTTP destination observations
  with stable finding fingerprints and active trace correlation. Findings are unvalidated candidate
  risks or observations, not confirmed vulnerabilities, and do not block application execution.
- Runtime snapshots of loaded PHP extensions and Composer packages with included files, with
  explicit partial completeness, bounded multipart delivery, and no synthetic artifact hashes.
- Default-off Security and local disk output, bounded source/event collection, and optional private
  JSONL/CycloneDX diagnostics. Request values and sink argument text are not serialized.
- Immutable security-spec commit and schema/fingerprint provenance in the installed package,
  diagnostics, and documented coverage, limitations, and local performance evidence.

Validation covers PHP 8.2/8.3/8.4, the pinned Beacon native extension, normative fingerprints,
emitted event schemas, real HTTP request isolation, official PDO instrumentation coexistence,
archive installation, and actual Collector receipt. This does not establish backend acceptance,
complete taint tracking, confirmed exploitability, or production/cross-platform performance bounds.
The Security capability remains experimental.

## Upgrade and enable

```bash
composer require beacon-observability/beacon-php:1.2.0
vendor/bin/beacon-php doctor

export BEACON_SECURITY_ENABLED=true
export OTEL_PHP_AUTOLOAD_ENABLED=true
export OTEL_SERVICE_NAME=my-php-service
export OTEL_LOGS_EXPORTER=otlp
export OTEL_EXPORTER_OTLP_PROTOCOL=http/protobuf
export OTEL_EXPORTER_OTLP_ENDPOINT=http://127.0.0.1:4318
```

Require the application's Composer autoloader before application code and enable an OTLP Logs
pipeline at the Collector. Enabling Security does not enable local files. See
[Security coverage and configuration](../../docs/security.md).

The native extension remains pinned to Beacon PHP Instrumentation 1.0.1 / upstream engine 1.4.2.
Application component spans continue to come from official OpenTelemetry Composer packages.
