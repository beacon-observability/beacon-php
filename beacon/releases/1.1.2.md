# Beacon PHP 1.1.2

Beacon PHP 1.1.2 aligns the Agent package with Beacon PHP Instrumentation 1.0.1.

The pinned native extension release provides verified binaries for PHP 8.2, 8.3, and 8.4 across Linux x86_64/arm64, macOS arm64, and Windows x86_64. Windows artifacts cover both NTS and TS builds. This release also adds PHP 8.3 to the Agent CI and release validation matrix and enforces the same immutable extension commit in both workflows.

Application instrumentation continues to come directly from official `open-telemetry/opentelemetry-auto-*` Composer packages; no `beacon-php-contrib` repository is required.

## Upgrade

```bash
composer require beacon-observability/beacon-php:1.1.2
vendor/bin/beacon-php doctor
```
