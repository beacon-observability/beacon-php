This release adds a unified installation entry point for Beacon PHP.

- Install the native extension and prebuilt Agent runtime with `beacon-setup.php`; default standalone mode requires no Composer and preserves application dependencies.
- Automatically load the Agent before application code, with isolated SDK dependencies and selected official PDO, cURL, Guzzle, Laravel and Symfony instrumentation.
- Use the same installer for diagnostics, upgrades, offline installation and removal. Existing startup configuration is preserved.
- Enable experimental Security and runtime SBOM explicitly with `--enable-security`; Composer project integration remains available as an advanced mode.

See the [installation guide](https://github.com/beacon-observability/beacon-php/blob/v1.3.0/README.md#installation) and [deployment details](https://github.com/beacon-observability/beacon-php/blob/v1.3.0/docs/standalone.md).
